#  gensim库中的Word2Vec使用

## 西游记

两段代码**分工完成【中文文本分词 → Word2Vec 词向量训练 → 词向量相似度计算】整套流程**，数据源是《西游记》txt 原著文本：

1. 第一段：读取原始小说 txt → jieba 分词 + 过滤停用词 → 输出分词后的文本文件
2. 第二段：加载分词好的文件 → gensim 训练 Word2Vec 词嵌入模型 → 向量查看、相似度、近义词推理计算





## 三国演义

整套代码分为**两大阶段：文本预处理分词 → 词向量模型训练 + 语义计算 + 模型持久化**，依托《三国演义》原文，完成从原始小说文本到可计算词语语义关系的词向量模型。

## 阶段 1：原始小说文本预处理（jieba 分词清洗）

1. 目录自动创建：代码自动生成`./three_kingdoms/segment`分词存放文件夹，避免目录缺失报错
2. 路径规划
   - `source`：存放未处理的《三国演义》原始 txt 小说文件
   - `segment`：存储分词处理完毕的文本文件
3. 批量分词逻辑
   - 读取 source 文件夹下全部 txt 文件，二进制方式读取文件内容（兼容各式编码，防止中文乱码）
   - 使用 jieba 库对全文进行精准分词，拆分整篇小说为一个个独立词语
   - 预留停用词过滤接口（当前停用词为空列表，可加载停用词表过滤标点、助词、虚词）
   - 分词词语用**空格隔开**写入新文件，该格式是 Word2Vec 模型规定的标准输入格式

## 阶段 2：基于分词文本训练两套 Word2Vec 模型 + 语义分析 + 模型保存

1. 读取分词数据集：通过`PathLineSentences`流式读取 segment 下所有分词文件，自动构造成模型可接收的训练数据集，大文件不会造成内存溢出

2. 训练

   测试小模型 model

   - 超参宽松：向量 100 维、窗口 3、`min_count=1`（所有出现过的词汇全部参与训练），只用来快速调试、查看基础语义效果

   - 两类语义测试：

     ① 查找和「曹操」语义最相似的词汇

     ② 向量运算：曹操 + 刘备 − 张飞，挖掘向量空间匹配的人物（含义：魏蜀两位主公，剔除武将张飞属性，匹配其他主公 / 谋士类人物）

3. 训练

   正式可用模型 model2

   - 优化超参：128 维向量、更大上下文窗口 5、`min_count=5`过滤低频生僻词、利用 CPU 多核全速训练，模型抗噪性、语义表征能力更强
   - 自动创建`three_kingdoms/models`目录，把训练好的模型保存到本地文件
   - 复用上面两组语义测试，对比宽松模型与优化模型的计算结果差异

4. sorted 排序：对相似度结果从高到低排序，直观展示匹配程度

==保存好的 word2Vec 模型，还能用来：人物聚类、文本相似度匹配、小说关键词提取、文本分类等 NLP 基础任务。==
