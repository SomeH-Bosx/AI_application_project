# 酒店描述文本完整流转路线（单线流程 + 每一步输入、操作、输出、作用）

原始文本字符串 → 文本清洗处理 → N-Gram 分词构建词袋词典 → 词频计数矩阵（词袋 BoW）→ TF-IDF 加权稀疏特征矩阵 → 两两余弦相似度方阵 → 依据相似度召回相似酒店推荐

## 分步详细链路

### 步骤 1：初始原始数据

输入：`df['desc']` 纯英文长文本字符串（酒店原始介绍文案，含大小写、标点、乱码、停用词）
操作：无处理
格式：文本字符串 Series
作用：数据集原始素材，无法被计算机运算

### 步骤 2：文本清洗预处理 clean\_text ()

输入：原始文本 `desc`
执行 4 项操作：

1. 全部字母小写统一格式
2. 标点符号替换为空格
3. 剔除特殊无效符号、乱码
4. 切割单词，删除英文停用词（the/and/is 等无意义虚词）
输出：新列 `df['desc_clean']` 干净标准化英文文本
作用：去除文本噪声、统一文本规则，避免符号、大小写、虚词干扰后续分词与权重计算

### 步骤 3：构建词袋词典 + N-Gram 切分（CountVectorizer）

输入：清洗完毕文本 `desc_clean`
操作：

1. 按照 `ngram_range=(1,3)` 切分：1 个单词、2 词短语、3 词短句全部提取
2. 遍历所有文本，汇总所有词组，生成全局词汇对照表（词典）
输出：固定词组词汇清单
作用：划定全部可用于表征酒店的特征单元，是后续向量生成的基础；同时依托该词典统计词频，画出高频词组柱状图，完成数据探索分析

### 步骤 4：生成词袋稀疏计数矩阵（BoW 词袋模型）

输入：清洗文本 + 全局词汇词典
操作：逐行统计每条文本内各个词组**出现总次数**
输出：Count 稀疏矩阵
形状：【酒店数量 行 × 总词组数量 列】
矩阵值：整数 = 词组出现次数
作用：将文字转为数字矩阵，实现文本数字化；缺陷：高频通用词汇权重过高，不适合相似度计算，仅用来做词频统计

### 步骤 5：词袋矩阵加权转换 → TF-IDF 稀疏权重矩阵（核心特征向量）

输入：词袋计数基础数据
操作：

1. 计算 TF（单文本内词组频次）
2. 计算 IDF（全局文档稀有度惩罚值）
3. TF × IDF 得到加权权重，向量默认 L2 归一化
输出：`tfidf_matrix` TF-IDF 稀疏矩阵
形状：【酒店数 × 特征词组数】
矩阵值：0~1 小数权重
每行含义：**单个酒店专属文本特征向量**
作用：弱化 hotel、room 这类通篇通用词汇权重，放大阳台、海景等酒店特色词汇权重；向量具备文本区分度，专门用于文本相似度运算

### 步骤 6：基于 TF-IDF 向量计算余弦相似度方阵

输入：TF-IDF 特征矩阵（所有酒店向量集合）
操作：调用`linear_kernel`线性核，两两酒店向量计算余弦相似度
输出：`cosine_similarities` N×N 稠密相似度方阵
方阵规则：`sim[i][j]` = 第 i 家酒店与第 j 家酒店的文案相似度；对角线值恒为 1
作用：量化任意两家酒店之间的风格相近程度

### 步骤 7：相似度矩阵检索，生成 TOP10 酒店推荐列表

输入：相似度方阵 + 酒店名称映射关系
操作：

1. 根据酒店名找到对应行索引
2. 取出该行全部相似度分数降序排序
3. 剔除自身，选取相似度最高前 10 个酒店
输出：10 个相似酒店名称列表
作用：完成内容推荐，输入一家酒店，推送文案描述最相像的酒店

## 精简一条总路线

原始英文文本 → 清洗去噪标准化文本 → N-gram 分词构建词汇表 → 词袋计数稀疏矩阵（频次统计）→ TF-IDF 加权特征稀疏矩阵（每行 = 酒店文本向量）→ N 阶两两相似度方阵 → 检索排序输出相似酒店推荐结果
